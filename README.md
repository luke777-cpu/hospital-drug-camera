# 본원 대체약 카메라 앱

휴대전화 카메라로 처방 화면/약봉투를 촬영하고, 판독된 약을 확인한 뒤 본원 약품 목록과 비교하는 설치형 웹앱(PWA) 시제품입니다.

## 결과 원칙

1. 성분·함량·제형이 확인된 본원 동일성분 후보
2. 동일성분이 없을 때만 병원 승인 대체 규칙에 따른 후보
3. 최종 선택과 처방은 의료진이 수행

현재 본원 목록은 기존 HTML의 340개 품목을 사용합니다. 사진 판독은 별도 병원 승인 서버가 필요하며, 앱 하단의 **사진 판독 연결**에서 주소를 설정합니다.

## 실행

정적 웹서버에서 이 폴더를 서비스합니다.

```bash
python -m http.server 8080 -d drug-camera-app
```

휴대전화에서 같은 주소를 열고 홈 화면에 추가합니다. 카메라 권한과 PWA 설치는 HTTPS 또는 localhost 환경이 필요합니다.

## 판독 서버 응답 형식

`POST multipart/form-data`, 이미지 필드명은 `image`입니다.

```json
{"drugs":[{"name":"클로피도그렐","strength":"75mg"},{"name":"아토르바스타틴","strength":"40mg"}]}
```

## 남은 임상 연결 작업

- 식약처 품목자료로 외부 상품명 → 표준 성분/함량/제형 확인
- 약제부가 승인한 치료군별 대체 규칙표 등록
- 본원 목록의 성분·함량 누락값 정비
- 실제 휴대전화 사진으로 판독 정확도 검증
- 병원 개인정보보호 기준에 맞는 온프레미스 또는 승인 API 선택
