본원 대체약 카메라 v2

실행 (보험 프로그램과 다른 폴더에서 사용)
1. 기존 보험 서버 검은 창에서 Ctrl+C를 눌러 종료합니다.
2. 이 ZIP을 새 폴더에 모두 풉니다.
3. 폴더 주소 표시줄에 cmd를 입력하고 Enter를 누릅니다.
4. py -3 server.py --lan 을 입력합니다.
5. PC IPv4에 PC의 현재 주소를 입력합니다. 최근 확인한 주소는 172.30.1.35입니다.
6. API 키를 입력합니다. 글자가 안 보이는 것이 정상입니다.
7. 같은 Wi-Fi의 휴대폰에서 서버가 표시한 http://주소:8765/ 를 엽니다.
8. 서버 창의 새 8자리 접속 암호를 입력합니다. 암호 화면의 제목은 '본원 대체약 연결'입니다.

사용
카메라 또는 사진 선택 → 전송 자료 확인 → AI로 약 목록 읽기 →
약 이름·성분·함량 대조 및 정정 → 대조 확인 체크 → 후보 목록 보기.
사진 대신 약 이름을 직접 입력해 AI로 판독할 수 있습니다.
AI 없이 본원 목록 검색은 본원 자료의 이름·성분 검색만 수행합니다.

① 동일 성분 후보: 사용자가 대조 확인한 성분·함량 문자열이 본원 자료와
일치한 항목만 표시합니다. 염을 제거하거나 비슷한 이름으로 일치시키지 않습니다.
표기 차이 때문에 같은 성분이 누락될 수 있습니다. 함량·제형·경로·방출형은 별도 확인합니다.
② 대체 검토 후보: AI가 본원 340종에서 최대 3종을 제안합니다.
환자별 대체 가능성이 검증된 규칙이나 허가사항 검색 엔진이 아닙니다.
의료진은 원문·공식 의약품 자료·환자 상태를 확인하고 최종 판단합니다.
판독 행을 수정하면 그 행의 기존 AI 대체 후보를 제외합니다. 필요하면 다시 AI 판독하세요.
투약 지시·용량 환산·자동 처방·EMR 저장 기능은 없습니다.

사진 또는 입력 문구와 본원 목록은 AI 판독 시 OpenAI로 전송됩니다.
식별정보를 미리 제거하세요. 자동 익명화·사진 자르기 기능은 없습니다.
API 키와 환자 입력은 앱에서 파일로 저장하지 않습니다. 브라우저/OS의 저장은 별개입니다.
LAN 접속은 HTTP이므로 신뢰하는 내부망에서만 사용하세요.
현재 GitHub Pages 주소와 별개로 이 PC 서버 주소에서 사진 판독을 사용합니다.
PC와 서버 창을 켜 두어야 합니다. 외부망 접속은 제공하지 않습니다.

문제가 있을 때
py 명령이 없으면 python server.py --lan 을 사용합니다.
포트 오류: 이전 보험/약 서버를 종료하고 다시 실행합니다.
401: API 키를 다시 확인. 429: API 결제/사용 한도를 확인합니다.
브라우저에서 예전 화면이 보이면 주소 끝의 / 를 포함해 새로 열어주세요.

검증: 모의 API 기반 자동 테스트. 실제 API 과금 호출, 판독 정확도와
Windows/아이폰에서의 최종 사용 흐름은 사용자가 확인해야 합니다.
