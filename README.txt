본원 대체약 카메라 v2.6

사진 판독 → ① 동일 성분 본원약 → 없으면 ② 동일 계열 본원약 전체 목록.
예: 본원에 없는 PPI 성분 → 란스톤LFDT, 에소메칸, 토프라졸.
함량이 달라도 동일 성분 목록에 표시하고 함량·경로는 각각 표시합니다.
진통제는 소염진통제, 아세트아미노펜계, 트라마돌계, 마약성으로 구분합니다.
계열 분류는 본원 목록과 AI 판독을 사용합니다. 판독 내용을 수정할 수 있습니다.
의료진이 최종 선택하며 자동 처방이나 용량 환산은 하지 않습니다.

실행
1. 기존 서버 창에서 Ctrl+C를 눌러 종료합니다.
2. ZIP을 새 폴더에 모두 풉니다. server.py 하나만 교체하면 안 됩니다.
3. 폴더 주소창에 cmd를 입력합니다.
4. py -3 server.py --lan 을 실행합니다.
5. 현재 PC IPv4 주소와 API 키를 입력합니다. 키 입력은 화면에 보이지 않습니다.
6. 같은 Wi-Fi의 휴대폰에서 표시된 http://PC주소:8765/ 를 엽니다.
7. 서버 창의 새 8자리 암호를 입력합니다. 서버 창은 계속 켜 둡니다.

사용
사진/약 이름 입력 → 전송 확인 → AI로 약 목록 읽기 → 결과 자동 표시.
필요하면 판독 내용의 약 이름·성분·계열을 고친 후 목록 갱신.
AI 없이 본원 목록 검색에서는 약 이름뿐 아니라 PPI, 진통제 등으로 검색할 수 있습니다.
GitHub Pages는 본원 목록 검색용입니다. 사진 AI 판독은 PC 서버에서 실행합니다.

주의 사항
사진·입력 문구와 본원 목록을 OpenAI로 전송합니다. 식별정보를 미리 잘라내세요.
API 키는 서버 메모리에만 보관합니다. 앱은 사진·환자 입력을 자동 저장하지 않습니다.
LAN은 HTTP이므로 신뢰하는 내부망에서만 사용합니다.
성분 표기 차이 때문에 동일 성분 검색이 누락될 수 있습니다. 염·복합제 성분은 보존합니다.
AI가 성분·계열을 잘못 읽을 수 있으므로 원문과 대조합니다.
동일 성분이라도 제형·방출형·투여경로·함량은 표시 내용을 보고 확인합니다.

검증
PPI 3종과 에소메칸 포함, 동일 성분 우선, 함량 차이, 계열 검색,
복합제·염 구분 테스트 및 서버 로그인·응답 테스트를 통과했습니다.
실제 API 판독 정확도와 Windows/아이폰 최종 동작은 별도 확인이 필요합니다.

외부 조회 (v2.6)
동일 성분이 없는 약은 약학정보원·식약처 도메인으로 웹 검색합니다.
약 이름·함량만 검색 입력으로 사용합니다. 실제 조회 출처 URL이 없는 결과는 채택하지 않습니다.
성분, 큰 약효분류, 세부 계열, 용도와 출처 링크를 표시합니다.
본원 목록과 세부 계열을 AI로 비교하고 투여경로가 다른 후보는 제외합니다.
외부 조회 실패 시 기존 사진 판독 결과를 보존하고 약별 재조회 버튼을 제공합니다.
분류와 후보는 출처 기반 AI 결과이며 자동 대체 처방이 아닙니다.
추가 웹 검색/API 비용이 발생합니다. 실 API 외부 조회는 사용자의 PC에서 확인이 필요합니다.
